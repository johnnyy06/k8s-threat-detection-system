# Screenshots — dashboard 04-per-scenario

Plasează aici screenshot-urile PNG cu numele propuse în README-ul părinte.

**Cum capturi un screenshot bun pentru teză:**
1. Deschide dashboard-ul în Kibana
2. Schimbă time range la "Last 7 days" (sau cel relevant pentru date)
3. Apasă Refresh — așteaptă să se încarce toate panel-urile
4. Click "Full screen" (sus-dreapta) pentru o vedere fără chrome Kibana
5. Screenshot OS-level (PrintScreen / Cmd+Shift+4 / etc.)
6. Salvează cu numele referențiat în README cu extensia `.png`

**Tip pentru defense:** capturile cu hover/tooltip pe panel-uri specifice arată valori exacte (ex: percentages pe treemap MITRE) — folosește-le pentru evidence concretă în Cap D.
